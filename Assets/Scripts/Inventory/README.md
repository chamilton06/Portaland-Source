Press tab to turn on/off the main inventory
Press 1-6 to assign that hotbar's item to the player's equipped slot.
Press 'a' to add an axe to the inventory (10 damage, max stack x1)
Press 's' to add a sword to the inventory (20 damage, max stack x2)

You can't drag and drop things as of writing this message.
You can't drop or pick up items (if you did drop them, you can't look down yet anyhow).
I broke the axe swinging animation doing this (sorry Kartikeya).

In theory you should be able to play around with testing items by either creating an item object in the project view (Create -> Weapon) or (Create -> Item). Items are not seen as weapons and cannot currently be used to attack. Weapons have properties which allow for them to be used to attack.
